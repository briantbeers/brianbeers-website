## Suggested nav order (buyer journey)

1. Orient → How franchising works  
2. Decide if the vehicle fits → Worth it?  
3. Define your box → Choose a model  
4. Diligence → Due diligence + validation + franchisor Qs  
5. Money → Funding + pro forma  
6. Proof in person → Discovery Day  
7. Risk filter → Red flags  
8. Close the loop → Attorney + decision  

Hub (`/franchises`) = complete guide TOC that maps the 12-step toolkit journey onto these pages.
